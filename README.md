# TP Apprentissage auto-supervisé

Aya Chihoub — Master 2 VMI

Le notebook `selfsupervised_tp.ipynb` contient le code, les sorties des démonstrations et les résultats des huit entraînements sur CIFAR-10 et CIFAR-100.

Méthodes comparées : Context Encoder, prédiction de rotation, SimCLR et prédiction de position relative de patches.

## Exécution

Importer le notebook dans Kaggle, activer GPU et Internet, puis exécuter les cellules dans l’ordre. Les résultats sont déjà visibles dans la version enregistrée. Les poids et les datasets ne sont pas inclus dans ce dépôt.
